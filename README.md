# JobCatalyst - Job Portal Application

## Overview

JobCatalyst is a full-stack job portal application that connects recruiters and job seekers through a centralized platform. Recruiters can post and manage job listings, while candidates can search and apply for opportunities.

## Features

- User authentication and authorization using Clerk.
- Role-based access control for recruiters and job seekers.
- Job posting and management functionality for recruiters.
- Job search and application features for candidates.
- Resume and image uploads using Cloudinary.
- RESTful APIs for job, application, and user management.

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: Clerk
- File Storage: Cloudinary
- Version Control: GitHub

## Installation & Setup

### Clone the Repository

```bash
git clone <repository-url>
cd job-catalyst
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file and add the required environment variables.

### Start the Application

```bash
npm run dev
```
